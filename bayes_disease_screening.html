例题 1 某疾病筛查的贝叶斯分析
【题目】某疾病的患病率为 1%。现有一种检测方法，灵敏度（真阳性率）为 99%，特异度（真阴性率）为 95%。
若某人检测结果为阳性，求此人真正患病的概率。
解 ①
定义事件，列出已知
A = 患病，B = 检测阳性
P(A) = 0.01 先验概率（患病率）
P(B|A) = 0.99 似然（灵敏度）
P(B|Ā) = 1 − 0.95 = 0.05 假阳性率 = 1 − 特异度
解 ②
用全概率公式求 P(B)
P(B) = P(B|A)·P(A) + P(B|Ā)·P(Ā)
= 0.99 × 0.01 + 0.05 × 0.99
= 0.0099 + 0.0495 = 0.0594
解 ③
代入贝叶斯公式
P(A|B) = P(B|A)·P(A) / P(B)
= 0.0099 / 0.0594
= 0.1667 = 16.67%
结论：即使检测阳性，真正患病的概率仅约 16.67%。
直觉解释：1000 人中 10 人患病（检出约 10 人），990 人健康（误报约 50 人），阳性中真正患病 10/(10+50) ≈ 16.7%。
例题 2 三家工厂产品合格率问题
【题目】甲、乙、丙三家工厂生产同一产品，产量分别占总量的 25%、35%、40%。
各厂的次品率分别为 5%、4%、2%。今从市场上随机买到一件次品，求该次品由甲厂生产的概率。
解 ①
定义事件，列出已知
A₁=甲厂, A₂=乙厂, A₃=丙厂, B=次品
P(A₁)=0.25, P(A₂)=0.35, P(A₃)=0.40 先验概率（产量占比）
P(B|A₁)=0.05, P(B|A₂)=0.04, P(B|A₃)=0.02 似然（各厂次品率）
解 ②
全概率公式求 P(B)
P(B) = Σ P(B|Aᵢ)·P(Aᵢ)
= 0.05×0.25 + 0.04×0.35 + 0.02×0.40
= 0.0125 + 0.0140 + 0.0080 = 0.0345
解 ③
贝叶斯公式
P(A₁|B) = P(B|A₁)·P(A₁) / P(B)
= 0.0125 / 0.0345
= 0.3623 = 36.23%
结论：买到的次品来自甲厂的概率为 36.23%。
虽然甲厂产量仅占 25%，但其次品率最高（5%），因此在次品中占比高于其产量占比。
类似可算：P(A₂|B)=40.58%, P(A₃|B)=23.19% — 乙厂贡献最多次品。
例题 3 考试作弊检测的贝叶斯分析
【题目】某校期末考试中，已知有 3% 的学生存在作弊行为。学校引入一套 AI 监考系统，
该系统对作弊学生的检出率为 90%（灵敏度），对正常学生的误报率为 8%。
若系统标记某学生为"疑似作弊"，该学生真正作弊的概率是多少？
解 ①
定义事件，列出已知
A = 作弊，B = 系统标记
P(A) = 0.03 先验（作弊率）
P(B|A) = 0.90 似然（灵敏度）
P(B|Ā) = 0.08 假阳性率
解 ②
全概率公式
P(B) = 0.90×0.03 + 0.08×0.97
= 0.027 + 0.0776 = 0.1046
解 ③
贝叶斯公式
P(A|B) = P(B|A)·P(A) / P(B)
= 0.027 / 0.1046
= 0.2581 = 25.81%
结论：被系统标记的学生中，真正作弊的概率仅 25.81%。
即约 74% 被标记的学生是无辜的！这说明：
① 低先验（作弊率仅 3%）会大幅拉低后验；② 即使系统"很准"，假阳性仍是大问题；③ 不能仅凭一次检测下结论。

🔗 基础贝叶斯 → 朴素贝叶斯：知识过渡

从概率论第一章的贝叶斯公式，到机器学习中的朴素贝叶斯分类器

1
基础贝叶斯公式
P(A|B) = P(B|A)·P(A) / P(B)
处理单一事件的条件概率翻转。
已知"检测阳性"推断"患病概率"。
核心：先验 + 似然 → 后验
→
2
多类别推广
P(y|B) = P(B|y)·P(y) / P(B)
从二分类推广到多分类。
如：工厂产品来自哪家？考试是否作弊？
分母用全概率公式展开：P(B) = Σ P(B|yᵢ)·P(yᵢ)
→
3
多特征引入
P(y|x₁,x₂,...,xₙ) = ?
现实问题往往有多个特征。
如文本分类：每个词都是一个特征。
直接计算 P(x₁,x₂,...,xₙ|y) 需要指数级数据！
→
4
朴素贝叶斯（关键假设）
P(y|X) ∝ P(y) · ∏ P(xᵢ|y)
"朴素"假设：特征之间条件独立
P(x₁,x₂|y) = P(x₁|y)·P(x₂|y)
将指数级问题简化为线性！
虽然假设不完全成立，但实践中效果出奇地好。

📋 结构对比：疾病筛查 vs 文本分类

组成部分 疾病筛查（基础贝叶斯） 文本分类（朴素贝叶斯）
先验 P(y) 患病率 P(病) = 1% 类别频率 P(spam) = 训练集中占比
似然 P(x|y) P(+|病) = 灵敏度 99% P("中奖"|spam) = 词频统计
证据 P(x) P(+) 全概率公式计算 归一化常数（预测时可省略）
后验 P(y|x) P(病|+) = 16.67% P(spam|"恭喜中奖") → 分类决策
特征数量 1 个（检测结果 +/−） n 个（文本中的每个词）
独立性假设 不需要（单一特征） 朴素假设：各词之间条件独立

🎛️ 超参数调整指南

患病率 P(病)
范围：0.1% ~ 15%（页面滑条）
影响：直接决定先验概率。患病率越低，即使检测很准，后验也越低（假阳性淹没真阳性）。
调参直觉：稀有疾病 → 先验极低 → 需要更高特异度才能保证后验。
灵敏度 P(+|病)
范围：50% ~ 100%（页面滑条）
影响：真阳性率。灵敏度越高，漏诊（FN）越少。
调参直觉：筛查场景要求高灵敏度（宁可误报不漏诊）；确诊场景更看重特异度。
特异度 P(−|健)
范围：50% ~ 100%（页面滑条）
影响：真阴性率。特异度越高，误报（FP）越少。
调参直觉：特异度对后验影响最大！从 95% 提到 99%，后验可能从 16% 跳到 50%。
拉普拉斯平滑 α
范围：0.01 ~ 10（Python 代码中调整）
影响：朴素贝叶斯专用。防止训练集中未出现的词导致概率为 0。
调参直觉：α=1 为标准拉普拉斯平滑；α→0 无平滑（过拟合）；α过大则欠拟合。
💡 实验建议：尝试将页面滑条调到极端值观察变化 —— 患病率调到 0.1%、特异度调到 90%，看后验如何暴跌；再将特异度拉到 99.9%，看后验如何回升。 这就是贝叶斯公式中先验与似然的博弈。
